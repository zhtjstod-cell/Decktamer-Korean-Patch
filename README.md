# Decktamer 1.7.4 한국어 패치

Decktamer 1.7.4의 비공식 한국어 패치입니다. 영어 원문 37개 표, 3,039개 문구를 GPT로 직접 번역하고 사람이 문맥과 게임 규칙을 대조해 다듬었습니다.

## 적용 내용

- UI, 튜토리얼, 카드·기술·특성, 이벤트, 도감, 설정, 전투 로그 전체 번역
- 제목·본문에 Noto Serif KR Regular/Bold 적용
- 수첩·설정 손글씨에 Nanum Pen Script 적용
- 한국어 → 다른 언어 → 한국어 전환 시 번역이 다시 로드되지 않는 캐시 문제 수정
- 장면 재로딩 뒤 새 전투 알림·이벤트가 영어로 폴백되는 중복 언어 초기화 문제 수정
- 언어 전환 뒤 사라지던 `선제공격`, `후공`, `전 라인 공격`, `대상` 등의 굵은 강조 및 도움말 복구
- Google 번역 결과를 사용하지 않은 GPT 직접 번역본

## 지원 버전

- 게임: **Decktamer 1.7.4 Windows**
- 다른 버전이나 이미 DLL/`sharedassets0.assets`를 수정하는 모드가 적용된 설치본에는 안전을 위해 적용되지 않습니다.

## 설치

1. 게임을 완전히 종료합니다.
2. [Releases](../../releases/latest)에서 ZIP 파일을 받고 압축을 풉니다.
3. `Install_Korean_Patch.bat`를 실행합니다.
4. 자동으로 게임을 찾지 못하면 `Decktamer.exe`가 있는 폴더를 선택합니다. 또는 게임 폴더를 배치 파일 위로 끌어다 놓습니다.
5. 게임 설정에서 언어를 **한국어**로 선택합니다.

게임이 `Program Files` 아래에 있어 쓰기 권한 오류가 발생하면 설치 배치 파일을 관리자 권한으로 실행하세요.

## 제거

게임을 종료한 뒤 `Uninstall_Korean_Patch.bat`를 실행합니다. 설치 시 만든 검증된 원본 백업으로 게임 파일을 복구하며, 한글패치 이전에 별도의 `ko` 번역 폴더가 있었다면 함께 복원합니다.

백업 위치:

```text
<게임 폴더>\KoreanPatch_Backup_1.7.4
```

안전을 위해 제거 후에도 백업 폴더는 자동 삭제하지 않습니다.

## 검증 범위

- 번역 표 37개 / 3,039행 / 키 순서 일치
- 원문이 있는데 번역이 비어 있는 항목 0건
- Smart String 변수와 TextMesh Pro 태그 불일치 0건
- 번역문 내 한자/CJK 혼입 0건
- 카드·특성·아이템의 키워드 강조 불일치 0건
- 폰트에 번역에서 사용하는 한글 음절 983개가 모두 포함됨
- 기존 일본어 글리프 인덱스와 한글 글리프 충돌 0건
- 설치·재설치·검증·제거 후 SHA-256 해시 검증

게임 화면의 최종 육안 검증은 사용자가 진행합니다. 오역이나 표시 문제는 스크린샷과 함께 이슈로 남겨 주세요.

## 배포 방식

이 저장소와 릴리스에는 게임 원본 DLL이나 Unity 에셋이 포함되지 않습니다. 설치 도구는 Decktamer 1.7.4 원본 파일의 SHA-256을 확인한 뒤, 변경된 바이트만 담은 델타를 적용합니다. 해시가 다르면 원본을 덮어쓰지 않고 중단합니다.
