# Decktamer 한국어 패치

Decktamer의 비공식 한국어 패치입니다. 영어 원문을 GPT로 직접 번역하고 문맥과 게임 규칙을 대조해 다듬었습니다.

현재 **Decktamer 1.8.6 Boss Update**와 1.7.4를 지원합니다. 설치 도구는 폴더 이름이 아니라 실제 게임 파일의 SHA-256으로 버전을 자동 판별합니다.

## 적용 내용

- UI, 튜토리얼, 카드·기술·특성, 이벤트, 도감, 설정, 전투 로그 전체 번역
- 1.8.6의 신규 보스 5종, 신규 크리처와 보스 러시 개편 문구 번역
- 제목·본문에 Noto Serif KR Regular/Bold 적용
- 수첩·설정 손글씨에 Nanum Pen Script 적용
- 한국어 → 다른 언어 → 한국어 전환 시 번역이 다시 로드되지 않는 캐시 문제 수정
- 장면 재로딩 뒤 새 전투 알림·이벤트가 영어로 폴백되는 중복 언어 초기화 문제 수정
- 언어 전환 뒤 사라지던 키워드 굵은 강조 및 도움말 복구
- Google 번역 결과를 사용하지 않은 GPT 직접 번역본

## 지원 버전

| 게임 버전 | 번역 표 | 문구 | 상태 |
|---|---:|---:|---|
| 1.8.6 | 37개 | 3,288개 | 최신 Boss Update 지원 |
| 1.7.4 | 37개 | 3,039개 | 지원 |

게임이 업데이트되어 파일 해시가 달라지면 알 수 없는 파일을 억지로 덮지 않고 중단합니다. 한글패치가 갱신된 뒤 `Update_Korean_Patch.bat`를 실행하면 GitHub 최신 릴리스를 내려받아 현재 게임에 적용합니다. 아직 배포되지 않은 게임 버전의 새 문구와 바이너리는 자동 번역·패치할 수 없으므로 새 버전 프로필이 공개될 때까지 기다려야 합니다.

## 설치

1. 게임을 완전히 종료합니다.
2. [Releases](../../releases/latest)에서 ZIP 파일을 받고 압축을 풉니다.
3. `Install_Korean_Patch.bat`를 실행합니다.
4. 자동으로 게임을 찾지 못하면 `Decktamer.exe`가 있는 폴더를 선택합니다. 또는 게임 폴더를 배치 파일 위로 끌어다 놓습니다.
5. 게임 설정에서 언어를 **한국어**로 선택합니다.

패치 폴더는 게임 폴더 안이나 밖 어디에 있어도 됩니다. `bat` 파일만 따로 옮기지 말고 압축 안의 폴더 구조를 유지하세요. 게임이 `Program Files` 아래에 있어 쓰기 권한 오류가 발생하면 관리자 권한으로 실행하세요.

## 게임 업데이트 뒤 패치 갱신

1. 게임을 완전히 종료합니다.
2. `Update_Korean_Patch.bat`를 실행합니다.
3. 최신 GitHub 릴리스가 있으면 ZIP의 SHA-256을 확인한 뒤 새 설치 도구로 전환합니다.

게임 업데이트 직후 아직 대응 릴리스가 없다면 현재 파일 해시와 최신 릴리스 주소를 표시하고 안전하게 중단합니다.

## 제거

게임을 종료한 뒤 `Uninstall_Korean_Patch.bat`를 실행합니다. 감지한 게임 버전에 맞는 검증된 원본 백업으로 복구하며, 한글패치 이전에 별도의 `ko` 번역 폴더가 있었다면 함께 복원합니다.

백업 위치:

```text
<게임 폴더>\KoreanPatch_Backup_<게임 버전>
```

안전을 위해 제거 후에도 백업 폴더는 자동 삭제하지 않습니다.

## 검증 범위

- 1.8.6 번역 표 37개 / 3,288행 / 키 순서 일치
- 신규 문구 256개와 변경 문구 8개 GPT 직접 번역
- 원문이 있는데 번역이 비어 있는 항목 0건
- Smart String 변수와 TextMesh Pro 태그 불일치 0건
- 번역문 내 한자/CJK 혼입 0건
- 카드·특성·아이템의 키워드 강조 불일치 0건
- 폰트에 번역에서 사용하는 한글 음절 999개가 모두 포함됨
- 기존 일본어 글리프 인덱스와 한글 글리프 충돌 0건
- 1.7.4와 1.8.6 각각 설치·재설치·검증·제거 후 SHA-256 검증

게임 화면의 최종 육안 검증은 사용자가 진행합니다. 오역이나 표시 문제는 스크린샷과 함께 이슈로 남겨 주세요.

## 배포 방식

이 저장소와 릴리스에는 게임 원본 DLL이나 Unity 에셋이 포함되지 않습니다. 설치 도구는 지원 버전의 원본 파일 SHA-256을 확인한 뒤 변경된 바이트만 담은 델타를 적용합니다. 해시가 다르면 원본을 덮어쓰지 않습니다.
